# Yuukun Portfolio

Engineer portfolio prototypes inspired by vintage clothing and vinyl records.

## Directory Structure

- `index.html`: prototype launcher
- `prototypes/v1/`: first portfolio mock
- `prototypes/v2/`: current source prototype for requirements
- `assets/images/`: shared image assets
- `references/`: imported reference UI, screenshots, and design notes
- `docs/requirements.md`: Japanese requirements draft based on v2
- `README.md`: Japanese README

## Current Focus

Use `prototypes/v2/index.html` as the basis for requirements discussion.

Open `index.html` in a browser to choose a prototype. The next step is to refine the real profile, skills, experience, projects, and contact flow based on the v2 direction.
