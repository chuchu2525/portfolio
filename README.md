# Yuukun Portfolio

古着とレコードをモチーフにした、エンジニア向けポートフォリオサイトの試作リポジトリです。

## ディレクトリ構成

- `index.html`: モック選択用の入口ページ
- `prototypes/v1/`: 最初に作成したモック
- `prototypes/v2/`: 現在の要件検討ベース
- `assets/images/`: 共通画像アセット
- `references/`: 参考UI、スクリーンショット、デザインメモ
- `docs/requirements.md`: v2をもとにした要件ドラフト
- `README-en.md`: English README

## 現在の進め方

要件固めの中心は `prototypes/v2/index.html` です。

まず `index.html` をブラウザで開くと、v1 / v2 のモックを選べます。今後は v2 の構成を見ながら、実際に載せるプロフィール、スキル、経験、プロジェクト、連絡導線を詰めていきます。
